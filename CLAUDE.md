# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Is

ZMK firmware configuration for a Sofle split ergonomic keyboard with:
- **Controller**: Nice!Nano v2 (nRF52840)
- **Display**: nice!view (left: layer info + WPM graph; right: Arasaka logo animation)
- **Left half**: EC11 rotary encoder (volume), RGB underglow, backlight
- **Right half**: analog joystick (mouse pointer), RGB underglow
- **Connectivity**: BLE split + BLE to host, compatible with Prospector Scanner dongle

## Build Process

Firmware is built exclusively via **GitHub Actions** — there is no local build command. Push to GitHub to trigger a build:

- `.github/workflows/build.yml` — calls ZMK's official `build-user-config.yml` workflow
- `build.yaml` — defines three artifacts: `sofle_left`, `sofle_right`, `sofle_reset`

The keymap SVG diagram in `keymap-drawer/sofle.svg` is auto-generated by a separate workflow (`.github/workflows/keymap_drawer.yaml`) whenever `config/*.keymap` or `config/config_keymap-drawer.yaml` changes.

## Layer Structure

| # | Name | Activated By |
|---|------|--------------|
| 0 | ColemakDH | Default |
| 1 | ColemakDH Alt | Hold left `PAUSE_BREAK` (also compose trigger) |
| 2 | QWERTY | `tog 2` from Settings layer |
| 3 | QWERTY Alt | Hold left `PAUSE_BREAK` while in QWERTY |
| 4 | Settings | Hold `TAB` (BT device select, RGB controls, toggle QWERTY) |
| 5 | Cursor | Hold right `mo 5` key (arrow keys, Home/End/PgUp/PgDn) |

## German Umlauts

Two distinct mechanisms are used together:

1. **Compose macros** (`uml_a`, `uml_u`, `uml_o`): Send `PAUSE_BREAK` → letter → `DOUBLE_QUOTES`. This uses the Linux Compose key sequence — Linux must have `PAUSE_BREAK` (or whichever key) configured as the Compose key.

2. **zmk-unicode** (`uc UC_DE_SS`, `uc UC_CURR_EURO`): Sends Unicode via the Linux input method configured by `HOST_OS 1` and `default-mode = <UC_MODE_LINUX>` in the keymap.

`PAUSE_BREAK` on the home row (left pinky) doubles as the compose trigger key — tapping it sends `PAUSE_BREAK`, holding it activates layer 1 (Alt layer) via `&lt 1 PAUSE_BREAK`.

## External ZMK Modules (west.yml)

- **zmkfirmware/zmk @ v0.3.0** — base firmware; all module revisions must match this
- **urob/zmk-unicode @ v0.3.0** — unicode character output (ß, €)
- **t-ogura/prospector-zmk-module @ v2.2.1** — enables `CONFIG_ZMK_STATUS_ADV_*` settings in `sofle_left.conf` for the Prospector Scanner dongle
- **siddhantac/nice-view @ main** — custom Arasaka animation on the right display

## Hardware Notes

- RGB underglow chain length is 7 LEDs (`sofle.dtsi`), driven via SPI3/WS2812
- Backlight uses PWM0 on pin P1.13 (`sofle_left.dts`)
- Display is SSD1306 OLED over I2C0 (128×32) — though nice!view overlays this via the adapter shield
- Battery monitoring via `zmk,battery-nrf-vddh` (left side)
- Deep sleep after 60 min (`CONFIG_ZMK_IDLE_SLEEP_TIMEOUT=3600000`)
- RGB auto-off on idle and USB (`CONFIG_ZMK_RGB_UNDERGLOW_AUTO_OFF_IDLE/USB=y`)
